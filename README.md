## Como construo

- **Edge-first.** Deploy tudo em Cloudflare Workers, D1 e Assets.
- **Sem framework quando dá.** HTML/CSS/JS vanilla resolve muita coisa e carrega mais rápido.
- **Design minimalista.** Uma cor de destaque, tipografia trabalhando forte, muito espaço em branco.
- **IA como ferramenta.** Uso Groq para partes que exigem linguagem natural, sem forçar onde não precisa.
